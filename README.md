# Armaan Garnayak — Portfolio

A single-file static portfolio site. No build step, no dependencies — just `index.html`.

## Run locally
Open `index.html` directly in a browser, or serve it:
```bash
python3 -m http.server 5500
```
Then visit http://localhost:5500

## Deploy
Deployed via [Vercel](https://vercel.com), connected to this GitHub repo. Any push to `main` redeploys automatically.
